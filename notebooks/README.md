# Reproduction notebooks

Download and extract the v1.1.0 result archive into `results/campaign/` as described in the main README. Each notebook validates the archive and invokes the publication pipeline before displaying its selected results. Run all cells from top to bottom. The notebooks require Jupyter; the command-line pipeline does not.

- `historical_scenario_analysis.ipynb`: Figure 2 and Table S3.
- `probabilistic_risk_analysis_pub.ipynb`: Figures 1, 3–5 and S1–S4, Table 1, and Tables S4–S6/S8.

The notebooks contain no stored execution output or local paths. Figure S1 uses the included published reference unless its restricted event-loss catalog is supplied to the command-line pipeline.
